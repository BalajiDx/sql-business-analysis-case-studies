# Data Dictionary

All data is **synthetic**, generated by `generate_dataset.py` (fixed random seed 7). No real bank, retailer or customer data is used.
Amounts are in INR. Banking transactions cover **Jan-Dec 2024**; retail orders cover **Jan 2023 - Dec 2024**.

## Banking schema (`Banking/`)

### Branches (12 rows)
| Column | Type | Description |
|---|---|---|
| BranchID | text, PK | `BR01`-`BR12` |
| BranchName | text | Branch name |
| City / Region | text | Location; regions are South-East, Chennai, Karnataka, Western TN, Southern TN |
| OpenedYear | int | Year the branch opened |

### BankCustomers (`Customers.csv`, 2,500 rows)
| Column | Type | Description |
|---|---|---|
| CustomerID | text, PK | `BC00001` onwards |
| Gender | text | F / M |
| Age | int | 19-75 |
| Segment | text | Mass, Mass Affluent, Affluent, MSME |
| HomeBranchID | text, FK | to Branches |
| JoinDate | date | Customer since |

### Accounts (3,811 rows)
| Column | Type | Description |
|---|---|---|
| AccountID | text, PK | `A000001` onwards |
| CustomerID | text, FK | to BankCustomers. Every customer has a savings account; some also hold Current / Fixed Deposit / Recurring Deposit |
| AccountType | text | Savings, Current, Fixed Deposit, Recurring Deposit |
| OpenDate / CloseDate | date | CloseDate is empty for open accounts |
| BranchID | text, FK | to Branches |

### Transactions (37,842 rows)
| Column | Type | Description |
|---|---|---|
| TxnID | text, PK | |
| AccountID | text, FK | to Accounts (savings and current accounts only) |
| TxnDate | date | 2024 |
| Channel | text | UPI, ATM, Branch, NetBanking, POS |
| Direction | text | Credit (money in) or Debit (money out). ATM transactions are always debits, capped at ₹40,000 |
| Amount | decimal | INR |

## Retail schema (`Retail/`)

### Stores (8 rows)
| Column | Type | Description |
|---|---|---|
| StoreID | text, PK | `S01`-`S08` (S08 is the online store) |
| StoreName / Format | text | Supermarket, Hypermarket, Express, Online |
| OpenDate | date | |

### Products (140 rows)
| Column | Type | Description |
|---|---|---|
| ProductID | text, PK | |
| ProductName / Category / Brand | text | 8 categories; generic product names |
| ListPrice / UnitCost | decimal | INR; cost is 62-82% of price |

### RetailCustomers (`Customers.csv`, 4,000 rows)
| Column | Type | Description |
|---|---|---|
| CustomerID | text, PK | `RC00001` onwards |
| City | text | |
| LoyaltyTier | text | None, Silver, Gold (Gold members buy most often) |
| FirstPurchaseDate | date | 2023-2024 |

### Orders (15,008 rows)
| Column | Type | Description |
|---|---|---|
| OrderID | text, PK | |
| CustomerID / StoreID | text, FK | |
| OrderDate | date | |
| Status | text | Delivered, Returned, Cancelled. Revenue scripts use **Delivered** only |
| PaymentMode | text | UPI, Card, Cash, Wallet |

### OrderItems (52,562 rows)
| Column | Type | Description |
|---|---|---|
| OrderItemID | text, PK | |
| OrderID / ProductID | text, FK | |
| Quantity | int | 1-4 |
| UnitPrice | decimal | List price at the time of sale |
| DiscountPct | decimal | 0, 0.05, 0.10 or 0.15 |

**Line revenue** = `Quantity * UnitPrice * (1 - DiscountPct)`. **Line margin** = line revenue - `Quantity * UnitCost`.
